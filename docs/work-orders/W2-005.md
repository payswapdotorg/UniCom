# W2-005 — Reality/Learning Lab + Model-Routing Evaluation

Lane: Worker 2
Status: READY
Dependencies: W2-004 (merged @ 2df3c88)

## Objective
Build the evaluation substrate for organizations, models, and skills: the **Reality Lab** (deterministic simulated commerce environments), the **Learning Lab** (evaluation + evidence), and the **7-way model-routing comparison** with the full promotion-gate chain (replay → adversarial evaluation → simulation → shadow → canary → observed-outcome evidence → promotion or rollback/retirement).

## Scope
Under `packages/agent` (module-system conforming), on top of the merged W2-002 agent kernel + W2-003 Opportunity Lab/promotion gates + W2-004 evidence journal/trust/immune-system/opportunity-graph: a Reality Lab — deterministic, seeded simulated commerce environments (simulated customers, merchants, providers, adversaries as scenario actors) driven by the existing kernel seams, no real provider calls, no real commerce-state mutation (commerce facts via the opaque seam only); a Learning Lab — evaluation runs that exercise configurations against Reality Lab scenarios, every run journaling hash-chained evidence into the W2-004 evidence journal; the 7-way model-routing comparison as a first-class evaluation battery: (1) Main Agent + skills baseline, (2) Main Agent + ephemeral delegates, (3) provider-native optimization, (4) searched organizations, (5) System 1 only, (6) System 1 + JEPA/world-model, (7) System 1 + JEPA + System 2 escalation — all seven executing the SAME scenario battery with measured outcomes (decision quality, cost, latency proxies as deterministic metrics); adversarial evaluation — the W2-004 fraud archetypes run against every configuration, evasion attempts detected (silent evasion is a bug); the full promotion chain as journaled state transitions: simulation → shadow → canary → observed-outcome evidence → promotion decision, each gate backed by evidence records and executable in tests; rollback/retirement — a promoted configuration can be retired with a journaled retirement decision + evidence; model-routing policy itself as deterministic policy application over journaled state (routing decisions journaled, replayable, never silent).

## Truth distinctions
Evaluations are deterministic: same seed + same configuration → same measured outcomes; evidence is hash-chained and append-only; promotion/retirement are journaled policy applications with complete gate evidence — never silent mutations; adversarial evasion that goes undetected is a bug, not a pass; simulated environments never mutate canonical commerce state; routing decisions are journaled + replayable.

## Acceptance scenarios
1. Reality Lab determinism: same seed → same environment trajectory (two runs, identical event streams + outcomes).
2. Evidence journaling: every evaluation run writes hash-chained evidence records (verified chain integrity).
3. 7-way comparison: all seven configurations execute the same scenario battery; outcomes measured + compared in a structured result (each configuration's metrics asserted present + internally consistent).
4. Adversarial evaluation: fraud archetypes (incl. EVASION variants) run against each configuration; detections + misses are explicit outcomes (a silent evasion fails the suite).
5. Promotion chain: simulation → shadow → canary → observed outcomes → promotion executes as journaled gate transitions with evidence at every gate; a gate without evidence blocks promotion (tested).
6. Rollback/retirement: a promoted configuration retires through a journaled decision with evidence; post-retirement the configuration no longer routes.
7. Routing policy determinism: the same journaled state + inputs → the same routing decisions (replay test).

## Constraints
No real provider/network calls (simulated providers only); no canonical commerce-state mutation (opaque seam reads only); no UI concerns (Worker 3 lane); no commerce-kernel changes (Worker 1 lane); deterministic seeds only, no wall-clock; no production mocks outside clearly-marked simulation doubles; no scope beyond the agent lane.
