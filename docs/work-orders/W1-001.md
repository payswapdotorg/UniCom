# W1-001 — Commerce Domain Contracts

Lane: Worker 1
Status: READY
Dependencies: none

## Objective

Define deterministic Commerce Kernel contracts without implementing agent optimization.

## Scope

Create canonical types/interfaces for:
- Principal/customer/merchant references;
- Product/Variant/SKU;
- Catalog/Collection;
- Price/Promotion;
- Inventory/Location;
- Cart;
- Checkout;
- Order/OrderLine;
- Payment intent boundary;
- Fulfillment/Shipment;
- Return/Exchange;
- Subscription;
- B2B price/customer context;
- resale/rental item state;
- CommerceEvent;
- Opportunity references;
- AutonomousStorePolicy.

Establish explicit state ownership and event sequencing.

## Required properties

- no floating-point money;
- immutable IDs;
- version/revision semantics;
- idempotency fields for consequential commands;
- UNKNOWN state where external observation may be ambiguous;
- no provider-specific semantics in commerce domain types;
- no direct model/runtime imports into domain truth.

## Acceptance

- contract tests;
- serialized examples;
- state transition diagrams;
- dependency graph updated only if necessary;
- no production mocks;
- typecheck/lint for affected packages.
