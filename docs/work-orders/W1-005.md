# W1-005 — Autonomous-Store Deterministic Runtime

Lane: Worker 1
Status: READY
Dependencies: W1-004 (merged @ 2df3c88)

## Objective
Compose the W1-004 autonomous-store primitives (store-ops vocabulary: opening/closing counts, till operations, staff-session handover, cash reconciliation) into the **autonomous-store deterministic runtime**: a store that operates itself through policy-driven, journaled, replayable command/event flows — opening/closing cycles, till management, in-policy price adjustments, autonomous restock/purchase triggers, variance handling, and human override — every autonomous decision a deterministic policy application the twin covers.

## Scope
Under `packages/commerce` (module-system conforming), on top of the merged W1-002 kernel runtime + W1-003 twin/projections + W1-004 store-ops: an autonomous-store runtime layer that composes the store-ops vocabulary into full operating cycles (open → operate → close → reconcile) as deterministic command/event sequences; autonomous store policies (opening/closing rules, till float bounds, in-band price adjustment rules, restock/reorder trigger rules, variance thresholds) expressed through the existing policy gate — every autonomous action gated + journaled as a policy application; autonomous inventory triggers (restock ordering + purchase-order initiation within policy bounds, folded into projections); in-policy price adjustments journaled + projection-visible with full before/after trails; variance + anomaly paths (cash variance at close, count mismatch, policy-band violation) as explicit journaled escalation states — never swallowed; human override + authority handover as journaled principal transitions with enforced authority boundaries (policy-gated: an override outside authority is rejected); deterministic time source for all store-cycle sequencing (NO wall-clock, NO unseeded randomness); replay determinism — any event-prefix replay reconstructs identical store state; twin-verification harness extended to the full autonomous surface (fuzz over interleavings incl. override + variance + failure paths).

## Truth distinctions
Autonomy is deterministic policy application over journaled state — never an unjournaled side effect; same event sequence → same store state, always; money is integer minor units; variance is an explicit journaled state, never an error to swallow; human override is a journaled principal transition with enforced authority, never a silent mutation; the twin remains the derived mirror — divergence is a bug the harness catches.

## Acceptance scenarios
1. Full store day: open → operate (till ops, sales, restock triggers) → close → reconcile folds deterministically end-to-end; a replay of the journal reconstructs the identical terminal state.
2. Autonomous restock: inventory at/below policy threshold → autonomous restock order + purchase-order initiation within policy bounds; out-of-band triggers are journaled policy violations (explicit state), not silent drops.
3. In-policy price adjustment: policy-band-legal adjustments apply + journal + project (before/after visible); out-of-band adjustments rejected with journaled policy rejections.
4. Variance + anomaly: cash variance at close + count mismatch land as explicit journaled escalation states with reconciliation events; nothing swallowed.
5. Human override + handover: override/handover are journaled principal transitions; an override outside the actor's authority is rejected by the policy gate (test both paths).
6. Determinism: no wall-clock, no unseeded RNG — a seeded fuzz over the autonomous surface holds twin ≡ kernel across arbitrary interleavings (incl. failure + override + variance).
7. Replay: arbitrary journal-prefix replay (checkpoint/resume from W1-003) reconstructs identical autonomous-store state at every prefix boundary.

## Constraints
No floating-point money; deterministic time source only; no opportunity/organization/agent semantics (Worker 2 lane — opaque references only); no UI or connector concerns (Worker 3 lane); no provider integrations; no production mocks (test doubles clearly marked); no scope beyond the commerce lane.
