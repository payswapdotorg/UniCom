## Objective

Deliver Stage 2 exactly as the decision record defines it (`docs/operator-decisions/commerce-plane-linking-decision-brief-2026-10-11.md` §4 + §8 — read both first; §8 is the authorization): the kernel-native commands **`LINK_GROUPBUY_TO_ORDER_DRAFT`** and **`LINK_TRADECYCLE_LEG_TO_SETTLEMENT_DRAFT`** — draft-creating only, with per-effect authorization records, idempotency keys, compensation references and UNKNOWN recovery, in the kernel's exhaustive test style.

## Required behavior (exactly)

1. **The commands** are additive on the existing public `@unicom/commerce` contract: no new package, no new dependency edge, no existing command/type signature changed. The kill switch refuses both commands with an honest "linking disabled" error (a typed refusal, never a silent no-op).
2. **Draft-creating only:** a linked draft is NOT an order, NOT a settlement, NOT a commitment. Payments/reservations/recourse are NEVER created by these commands — they remain separately-authorized commands a human issues against a linked draft.
3. **Idempotency (law 1/3):** a duplicate link command with the same idempotency key returns the ORIGINAL receipt — never a second draft.
4. **Authorization (law 2/4):** only the authorized actor may link (per the aggregate's consent basis — e.g. the GroupBuy organizer-side authority, the TradeCycle leg's receiver); an unauthorized actor is refused with the typed denial naming who may.
5. **Separation (law 3):** the linked draft is separate from its source aggregate — canceling the upstream aggregate marks downstream drafts `CANCELLED_BUT_NEVER_COMMITTED` (the cancellation cascade, honestly rendered); the upstream aggregate's own lifecycle is never mutated by linking.
6. **Compensation (law 5):** compensation requires its OWN authorization — a linked draft carries a compensation reference but nothing compensates automatically.
7. **UNKNOWN (law 6):** a pending downstream result surfaces UNKNOWN — never guessed, never faked.
8. **Per-leg isolation (law 7):** linking/refusing one TradeCycle leg never links another — each leg's link is independent.
9. **Provenance on every artifact:** every draft + receipt records the source aggregate id, the source kind, the acting principal and the consent basis (the same vocabulary Stage 1 renders host-side).
