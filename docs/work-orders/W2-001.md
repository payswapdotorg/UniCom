# W2-001 — Agent, Trust, Capability and Coordination Contracts

Lane: Worker 2
Status: READY
Dependencies: none

## Objective

Define the intelligence/network contracts that let one Main Agent reason over commerce capabilities and form bounded organizations.

## Scope

Define:
- AgentPrincipal;
- MainAgent;
- Skill;
- Tool;
- CapabilityDefinition;
- ProviderImplementation;
- ConnectedCapabilityInstance;
- CapabilityObservation;
- Strategy;
- Organization;
- ephemeral Delegate;
- delegation attenuation;
- UserTrust;
- AgentTrust;
- CapabilityTrust;
- TransactionProof;
- GroupBuy;
- CoordinationRequest;
- TradeCycle;
- Opportunity;
- BuyerCommerceIntent;
- security Signal;
- ThreatSignature;
- ModelRoute;
- Experiment/Evaluation.

## Critical rules

- one Main Agent remains the principal identity;
- skills are the default specialization;
- delegates are bounded and attenuated;
- strategy != organization;
- executable capability requires connected instance + observation;
- UserTrust != AgentTrust;
- proof is independent from trust;
- GroupBuy and TradeCycle are explicit objects;
- production trade cycles have a bounded hop limit;
- defensive threat signatures are not weaponized exploit payloads.

## Acceptance

- contract tests;
- lifecycle/state diagrams;
- privacy/authorization rules;
- sample group-buy flows;
- sample 3-hop trade cycle;
- security signature examples;
- no model direct-write authority.
