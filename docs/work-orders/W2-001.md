# W2-001 — Agent, Trust, Capability and Coordination Contracts

Lane: Worker 2
Status: COMPLETE
Dependencies: none

## Objective
Define the intelligence/network contracts that let one Main Agent reason over commerce capabilities, discover opportunities and form bounded organizations.

## Scope
Define AgentPrincipal/MainAgent, Skill/Tool, CapabilityDefinition, ProviderImplementation, ConnectedCapabilityInstance, CapabilityObservation, Strategy, Organization, ephemeral Delegate, attenuated delegation, UserTrust, AgentTrust, CapabilityTrust, TransactionProof, GroupBuy, CoordinationRequest, TradeCycle, Opportunity, BuyerCommerceIntent, Security Signal, ThreatSignature, ModelRoute and Experiment/Evaluation.

## Acceptance scenarios
1. Buyer intent with deadline, maximum cost, quality, privacy, security and speed.
2. Detect existing group-buy.
3. Detect latent demand and propose new group-buy to merchant agent.
4. Bounded three-user TradeCycle.
5. Unused owned item → resale/rental opportunity.
6. Fake review/review-ring signal.
7. Seller ships different product signal.
8. Buyer falsely claims different product signal.
9. UserTrust and AgentTrust represented independently.
10. P0–P5 proof selection.
11. System 1 → JEPA → System 2 escalation.

## Critical rules
One Main Agent remains the principal identity; skills are default specialization; delegates are bounded/attenuated; strategy != organization; executable capability requires connected instance + observation; trust != proof; GroupBuy and TradeCycle are explicit; production cycles are bounded; threat signatures are defensive only.
