# W2-006 — Organization/Model/Skill Promotion Gates + Adversarial Suite

Lane: Worker 2
Status: ACTIVE
Dependencies: W2-005 (merged)

## Objective
The terminal trust deliverable: the complete promotion-gate system for organizations, models, and skills + the full adversarial suite that gates the final release candidate. Nothing promotes to production authority without passing every gate with evidence; every adversary the system claims to detect, it must prove it detects.

## Scope
Under `packages/agent` (module-system conforming), building on the fully merged lane (W2-001..005 incl. the Reality/Learning Lab + 7-way evaluation): unified promotion gates for organizations, models, and skills — one journaled gate chain (simulation → adversarial evaluation → shadow → canary → observed-outcome evidence → promotion/retirement) parameterized per promotion subject-type, every gate evidence-backed through the hash-chained evidence journal; the complete adversarial suite as a first-class release gate — the five fraud archetypes with all EVASION variants (silent evasion is a bug — proven), plus adversarial cases for: trust-journal tampering attempts, quarantine escape, capability-scope escalation, broadcast forgery, opportunity-graph poisoning, promotion-gate bypass (a subject attempting to skip or fake gates), retirement circumvention; adversarial evaluation of the promotion system itself (gate-order violations rejected, evidence forgery rejected, replayed evidence rejected); immune-system response certification — every detected adversary triggers the correct journaled immune response (quarantine, broadcast, capability revocation) with reversibility proven; promotion-gate integration with the Reality Lab scenarios from W2-005 (promotions measured against the same deterministic scenario batteries, results comparable across subjects); a release-candidate adversarial report as code — machine-readable per-adversary DETECTED/EVASION-BLOCKED results consumable by the release gate.

## Truth distinctions
Promotion without complete gate evidence is impossible by construction (the gate chain rejects, and the rejection is journaled); evidence is hash-chained and forgery-resistant (forgery attempts are themselves detected + journaled adversaries); silent evasion is a bug, not a pass; retirement is as journaled and reversible as promotion; the adversarial suite gates the release — a claimed-but-unproven detection is a FAIL.

## Acceptance scenarios
1. Unified gate chain: organization + model + skill subjects each traverse simulation → adversarial → shadow → canary → observed-outcome → promotion with per-gate evidence; a missing gate blocks (tested per subject type).
2. Fraud archetypes: all five archetypes with all EVASION variants detected across every evaluated configuration — zero silent evasions.
3. Trust-journal + evidence integrity: tampering attempts, forged evidence, replayed evidence all detected + journaled as adversaries.
4. Quarantine/revocation reversibility: immune responses (quarantine, capability revocation, broadcast) execute journaled + reversible.
5. Promotion bypass: gate-order violations + gate-skip attempts rejected + journaled.
6. Retirement: journaled, evidence-backed; post-retirement subjects hold no authority (tested).
7. Adversarial report: machine-readable per-adversary results consumable by the release gate; ALL DETECTED/BLOCKED.

## Constraints
Gate/adversarial work only — no new organization/model semantics beyond what promotion requires; no cross-lane changes; deterministic evaluations (no wall-clock, no unseeded RNG); all existing suites stay green (cumulative).

## Unlocks
Release candidate (with W1-006 + W3-006 + the feature matrix gate).
