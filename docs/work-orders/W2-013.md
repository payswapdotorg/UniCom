## Objective

Replace the local demo state machines of the two buyer/peer surfaces with
**real kernel-driven execution** through the permitted public entrypoint
(`web → @unicom/commerce` via `contract.ts` only):

- **J9 TradeCycle** (`packages/web/src/commerce-modules/peer-tradecycle/`):
  the module's local consent machine (which mirrors the engine's laws and
  states "Not wired (blocker)" on-surface) becomes kernel-driven — per-leg
  consent/refusal submits real kernel commands; CONSENTED / REFUSED /
  STOPPED_REFUSAL outcomes come back from kernel truth; "No other leg was
  committed" becomes a real kernel outcome rendered from the aggregate, not
  mirrored text. The on-surface boundary statement is replaced by the honest
  new state: executed by the commerce kernel (demo fixtures still supply the
  candidates and identities, DEMO-labeled).
- **J5 buyer side** (`packages/web/src/commerce-modules/buyer-groupbuy/`):
  interest/withdraw/second-confirmation submit real kernel commands against
  the W1-012 formation aggregate; threshold MONITORING, HELD pools and
  FORMED-with-final-terms outcomes render from kernel truth; the
  "formation-engine boundary honestly (no simulated live outcome)" test
  expectation is superseded by kernel-driven outcomes; the two-step
  commitment rule (interest ≠ commitment; second confirmation against the
  formed deal's final terms) is enforced by the kernel, not local state.

## Interface and implementation rules

- Consume the kernel ONLY through `@unicom/commerce` public entrypoint
  imports (the W1-012 seam exports). Never deep-import; never edit
  `packages/commerce/**`.
- Own ONLY `packages/web/src/commerce-modules/peer-tradecycle/**` and
  `packages/web/src/commerce-modules/buyer-groupbuy/**` (+ their test
  files). No host/router/shared-contract edits; no merchant-* edits; no
  experience/agent edits.
- Preserve everything the rendered-UI phase certified: the rendered consent
 /refusal/stop flows and their browser-evidenced selectors
  (`cm-tradecycle-leg-*`, STOPPED_REFUSAL copy), accessibility, permission
  gates (`groupbuy.join`, `groupbuy.organize`, `trade.propose` — exact
  holders per the host contract), role-gated actions with visible reasons,
  DEMO data labels (synthetic identities/values stay labeled), deterministic
  reset, fixed demo clock.
- Unknown/kernel-pending states render as UNKNOWN (never FAILED); kernel
  errors surface honestly with safe recovery.
- Component tests upgraded from local-state assertions to kernel-driven
  scenarios (including: refusal stops without committing other legs;
  withdraw before second confirmation; duplicate submission idempotency).
- No live commerce side effects of any kind; no browser runs at lane level
  (RAM ceiling — the TL merged-lineage browser gate is the authority).

- Lane battery green (vitest), lint 0 errors (baseline warnings unchanged),
