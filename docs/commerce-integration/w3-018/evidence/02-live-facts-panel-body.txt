What this board will never do

It will never show a fabricated "connected" chip, a fabricated "last synced" timestamp, or a successful live attempt in an environment with no provider. UNAVAILABLE is not DISCONNECTED (there is nothing to disconnect), DEMO is not CONNECTED (it is local and deterministic), an ATTEMPT is not a success, REGISTERED is not CONNECTED (the adapter exists in the runtime; no account is bound), and a health UNKNOWN is neither healthy nor down — the runtime says so itself. The status vocabulary stays honest so the operator can trust the one state that matters: nothing is live.
