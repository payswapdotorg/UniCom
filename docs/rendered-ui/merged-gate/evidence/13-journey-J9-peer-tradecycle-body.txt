J9 · Trade cycles — multi-hop swaps
DEMO

A trade cycle chains gives-and-wants across several participants so everyone both gives and receives. The law of this surface: every leg needs its own consent from the giving participant — a refusal, a dropout or an expired consent window stops or re-plans the whole cycle. Other legs are never silently committed: a stop is a stop.

What is real here, and what is not

Real: The per-leg terms, the per-leg consent lifecycle (consent / refusal / withdrawal / expiry), the stop-and-re-plan mechanics — all deterministic demo state mirroring the coordination laws.

Demo-only: The candidate cycle itself. Discovery (bounded search over the offer graph) and validation (per-leg authorization checks) run in the agent lane, which the web host cannot import — candidates here are committed demo fixtures.

Not wired (blocker): Execution. Even with every leg consented, no trade leg executes in this host: the commerce seam carrying per-leg authorizations is agent-lane. The hand-off panel below records the request honestly — it never simulates a completed trade.
